# Є-Гідність Pro Flutter

Професійний локальний демонстраційний Flutter-додаток цифрового простору школи.

## Реалізовано
- сучасний Material 3 UI/UX;
- адаптивна навігація: bottom navigation на телефоні, sidebar на широких екранах;
- чати, пошук, повідомлення та composer;
- профіль + цифрова Є-Гідність ID;
- QR ID та демонстраційне сканування;
- класи/спільноти;
- новини з деталями;
- адмін-панель зі статистикою, користувачами, класами, новинами, модерацією, скаргами та журналом;
- світла/темна тема;
- легкі анімаційні переходи Material без важких залежностей;
- локальне збереження сесії, теми та повідомлень через SharedPreferences;
- responsive layout для телефонів і планшетів;
- мінімальна кількість залежностей для стабільності та швидкої збірки.

> QR/Дія/сканер тут є локальними демонстраційними сценаріями. Реальна інтеграція з державними або шкільними backend/API потребує окремих API-ключів, серверної частини та юридичної інтеграції.

## Збірка APK
У середовищі з Flutter 3.24+:

```bash
flutter pub get
flutter create --platforms=android .
flutter build apk --release
```

Готовий APK буде в `build/app/outputs/flutter-apk/app-release.apk`.

## GitHub Codespaces / Actions
У репозиторії є workflow `.github/workflows/build-apk.yml`, який створює Android-платформу, збирає release APK та публікує його як artifact.
